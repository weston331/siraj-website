## طرق الحصول على اللقطات:

### 1. من جهاز Android حقيقي:
```bash
# قم بتوصيل الهاتف وتفعيل USB Debugging
adb devices
adb shell screencap -p /sdcard/screenshot.png
adb pull /sdcard/screenshot.png .
```

### 2. من Flutter:
```bash
cd "c:\Users\Mohammed\Desktop\New folder (2)"
flutter run --device-id=<device_id>
# ثم اضغط 's' لأخذ screenshot
```

### 3. من Android Studio Emulator:
- افتح الإميوليتر
- شغّل التطبيق
- اضغط على أيقونة الكاميرا في شريط الأدوات
- احفظ في هذا المجلد

### 4. استخدام أدوات تصميم:
- Figma / Adobe XD / Sketch
- يمكنك تصميم موكبات احترافية للشاشات

## مواصفات الصور المثالية:

- **الصيغة:** PNG (للشفافية) أو JPG (أصغر حجماً)
- **الأبعاد:** 1080x2400 px (نسبة 9:20)
- **الجودة:** عالية (لا ضغط مبالغ فيه)
- **الحجم:** أقل من 500KB لكل صورة (للأداء الأفضل)

## التحسين الاختياري:

### ضغط الصور (لتحسين الأداء):
```bash
# باستخدام imagemagick
magick convert home.png -quality 85 -resize 1080x2400 home-optimized.png

# أو استخدم أدوات أونلاين:
# - TinyPNG.com
# - Squoosh.app
```

### تحويل إلى WebP (اختياري):
```bash
cwebp -q 85 home.png -o home.webp
```

## حالياً:

لإزالة الـ placeholders، ببساطة ضع الصور الحقيقية بنفس الأسماء في هذا المجلد.
